# Demo Recording Guide

The hosted demo is available at:

https://sentry-fraud-intelligence.vercel.app/

Record a 45-60 second walkthrough using this sequence:

1. Open the dashboard and point out the risk summary, transaction flow graph, and recent signals.
2. Open **Investigations**, search for `A001`, and open the account investigation.
3. Show the account owner, linked device, transactions, and connected-entity graph.
4. Open **Fraud Signals**, expand a signal, and show its evidence.
5. Open **Settings** to show the live API configuration.

The repository contains product screenshots in `docs/screenshots/`. A shareable
video URL should be added here after recording because video hosting requires an
account or storage destination owned by the project team.
